What should the core AI use case map look like?

This is the centerpiece of the tool — the visual that replaces Ardoq's architecture graph for AI governance

A — Relationship Graph

Ardoq-style node-link diagram. Use cases at center, connected to models, owners, risks, and mitigations. Interactive — click a node to explore. Familiar to the Ardoq CPO.

B — Risk Matrix

Use cases as rows, risk categories as columns. Color-coded heat map. Fast to scan, great for CISO reporting. Less "architecture diagram", more operational dashboard.

Each AI use case moves through stages: Discover → Map → Assess → Own → Mitigate. Progress tracking per use case. Makes Ardoq's gap obvious — they have no lifecycle concept.

You can select multiple — these can coexist as different views of the same data.
